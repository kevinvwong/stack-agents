# Module: api-usage

Tracks API call telemetry across four layers into a single Neon table. Default in all nextjs presets. No additional services — writes go to the same Neon DB as the rest of the app.

## What gets tracked

| Layer | What | Default |
|-------|------|---------|
| Anthropic | model, tokens in/out, cost estimate, latency, user_id | on |
| External APIs | service (deepgram/elevenlabs/etc.), endpoint, status, latency | on |
| Route calls | path, method, status, latency, user_id | on |
| DB queries | table, query type, duration, row count | **off** — use `--track-queries` to enable |

**Payloads (prompt text, audio, response body) are never stored by default.** Set `LOG_API_PAYLOADS=true` for debugging only — this is a GDPR footgun.

## Why Neon over alternatives

- Zero additional services — same DB, new table
- SQL queries: "total spend for user X this month", "slowest routes this week", all without a separate analytics product
- Works with existing Drizzle schema
- Reads back in dashboards via Recharts (if that module is installed)

## Why batching is required

A naive per-call INSERT to track DB queries causes every tracking write to be its own trackable query — infinite loop, doubled DB load. The write buffer flushes every 5 seconds (configurable) or at N=50 events, whichever comes first. Route tracking and Anthropic tracking are stateless enough to write immediately, but all writes go through the same buffer to be safe.

## Pricing constants

Prices change. Don't hardcode them inline — use a constants file so a price update is one edit.

**lib/ai/pricing.ts:**
```ts
// Input/output cost in USD per 1M tokens.
// Update when Anthropic changes pricing: https://anthropic.com/pricing
export const ANTHROPIC_PRICING: Record<string, { input: number; output: number }> = {
  "claude-opus-4-7":            { input: 15.00,  output: 75.00  },
  "claude-sonnet-4-6":          { input: 3.00,   output: 15.00  },
  "claude-haiku-4-5-20251001":  { input: 0.80,   output: 4.00   },
  // fallback for unknown models
  "unknown":                    { input: 3.00,   output: 15.00  },
};

export function estimateCost(
  model: string,
  inputTokens: number,
  outputTokens: number
): number {
  const pricing = ANTHROPIC_PRICING[model] ?? ANTHROPIC_PRICING["unknown"];
  return (inputTokens * pricing.input + outputTokens * pricing.output) / 1_000_000;
}
```

## Write buffer

All inserts go through a shared in-memory buffer. Flushes every 5 seconds or at 50 events, whichever comes first. This prevents DB query tracking from creating a write loop and decouples tracking latency from request latency.

**lib/usage/buffer.ts:**
```ts
import { db } from "@/lib/db";
import { apiUsage } from "@/db/schema";

type UsageEvent = typeof apiUsage.$inferInsert;

const buffer: UsageEvent[] = [];
let flushTimer: ReturnType<typeof setInterval> | null = null;

const FLUSH_INTERVAL_MS = 5_000;
const FLUSH_BATCH_SIZE = 50;

function scheduleFlush() {
  if (flushTimer) return;
  flushTimer = setInterval(flush, FLUSH_INTERVAL_MS);
}

async function flush() {
  if (buffer.length === 0) return;
  const batch = buffer.splice(0, FLUSH_BATCH_SIZE);
  try {
    await db.insert(apiUsage).values(batch);
  } catch (err) {
    // Silent failure — tracking must never break the application
    if (process.env.NODE_ENV === "development") {
      console.error("[api-usage] flush error:", err);
    }
  }
}

export function trackEvent(event: UsageEvent) {
  if (process.env.DISABLE_API_USAGE_TRACKING === "true") return;
  buffer.push(event);
  if (buffer.length >= FLUSH_BATCH_SIZE) flush();
  else scheduleFlush();
}
```

**Important:** The buffer is module-level state. In Vercel serverless, each invocation is stateless — the buffer may flush at the end of the request or not at all if the function is cold-started and immediately shut down. For high-fidelity tracking, call `flush()` explicitly at the end of long-running jobs. For route tracking, write immediately (no buffer) since the response is already sent.

## Wiring: Anthropic

Wrap the Anthropic client to intercept `messages.create()` and read `usage` from the response.

**lib/ai/client.ts** (updated):
```ts
import Anthropic from "@anthropic-ai/sdk";
import { estimateCost } from "./pricing";
import { trackEvent } from "@/lib/usage/buffer";

const _anthropic = new Anthropic({ apiKey: process.env.ANTHROPIC_API_KEY! });

export const models = {
  heavy: process.env.ANTHROPIC_MODEL_HEAVY ?? "claude-opus-4-7",
  standard: process.env.ANTHROPIC_MODEL_STANDARD ?? "claude-sonnet-4-6",
  light: process.env.ANTHROPIC_MODEL_LIGHT ?? "claude-haiku-4-5-20251001",
} as const;

type CreateParams = Parameters<typeof _anthropic.messages.create>[0];

export const anthropic = {
  messages: {
    async create(params: CreateParams, opts?: { userId?: string; sessionId?: string }) {
      const start = Date.now();
      try {
        const response = await _anthropic.messages.create(params);
        const latencyMs = Date.now() - start;
        trackEvent({
          kind: "anthropic",
          userId: opts?.userId,
          sessionId: opts?.sessionId,
          model: response.model,
          inputTokens: response.usage.input_tokens,
          outputTokens: response.usage.output_tokens,
          costUsd: estimateCost(response.model, response.usage.input_tokens, response.usage.output_tokens),
          latencyMs,
        });
        return response;
      } catch (err) {
        trackEvent({
          kind: "anthropic",
          userId: opts?.userId,
          model: (params as any).model,
          latencyMs: Date.now() - start,
          error: err instanceof Error ? err.message : String(err),
        });
        throw err;
      }
    },
  },
};
```

## Wiring: External APIs

Wrap the external API calls at the SDK level — don't wrap global `fetch` (SDKs may use their own HTTP stack).

**lib/voice/tts.ts** (ElevenLabs, updated):
```ts
import { ElevenLabsClient } from "elevenlabs";
import { trackEvent } from "@/lib/usage/buffer";

const client = new ElevenLabsClient({ apiKey: process.env.ELEVENLABS_API_KEY! });

export async function synthesizeStream(text: string, voiceId?: string, userId?: string) {
  const start = Date.now();
  try {
    const stream = await client.textToSpeech.convertAsStream(
      voiceId ?? process.env.ELEVENLABS_VOICE_ID!,
      { text, model_id: "eleven_turbo_v2", output_format: "mp3_44100_128" }
    );
    trackEvent({ kind: "external", service: "elevenlabs", endpoint: "/v1/text-to-speech", latencyMs: Date.now() - start, statusCode: 200, userId });
    return stream;
  } catch (err) {
    trackEvent({ kind: "external", service: "elevenlabs", endpoint: "/v1/text-to-speech", latencyMs: Date.now() - start, error: err instanceof Error ? err.message : String(err), userId });
    throw err;
  }
}
```

import { trackEvent } from "@/lib/usage/buffer";

const deepgramClient = createClient(process.env.DEEPGRAM_API_KEY!);

export async function transcribeAudio(audioBuffer: Buffer, userId?: string): Promise<string> {

    trackEvent({ kind: "external", service: "deepgram", endpoint: "/v1/listen", latencyMs: Date.now() - start, error: err instanceof Error ? err.message : String(err), userId });
    throw err;
  }
}

## Wiring: Routes

Use Next.js `middleware.ts` for response-time tracking. Middleware runs before routes — record entry, add a timing header, then log after response.

**middleware.ts** (updated — add tracking to existing middleware if present):
```ts
import { NextRequest, NextResponse } from "next/server";
import { trackEvent } from "@/lib/usage/buffer";

export function middleware(req: NextRequest) {
  const start = Date.now();
  const response = NextResponse.next();

  // Only track /api/* routes — exclude health checks and static
  if (req.nextUrl.pathname.startsWith("/api/")) {
    // Track after response — use waitUntil if available
    const latencyMs = Date.now() - start;
    trackEvent({
      kind: "route",
      method: req.method,
      path: req.nextUrl.pathname,  // no query params — avoid PII in URLs
      latencyMs,
      // status code not available in middleware — captured by route handler if needed
    });
  }

  return response;
}

export const config = {
  matcher: ["/api/:path*"],
};
```

For status code tracking, call `trackEvent` explicitly at the end of individual route handlers:

```ts
// app/api/chat/route.ts
import { trackEvent } from "@/lib/usage/buffer";

export async function POST(req: NextRequest) {
  const start = Date.now();
  // ... handler logic ...
  trackEvent({ kind: "route", method: "POST", path: "/api/chat", statusCode: 200, latencyMs: Date.now() - start, userId });
  return Response.json({ ... });
}
```

## Wiring: DB queries (opt-in, `--track-queries`)

Only enable if you explicitly pass `--track-queries`. Risk: any bug in the tracking write path causes infinite recursion.

**lib/db/index.ts** (updated, queries opt-in only):
```ts
import { neon } from "@neondatabase/serverless";
import { drizzle } from "drizzle-orm/neon-http";
import * as schema from "@/db/schema";
import { trackEvent } from "@/lib/usage/buffer";

const sql = neon(process.env.DATABASE_URL!);

const logger = process.env.TRACK_DB_QUERIES === "true"
  ? {
      logQuery(query: string, params: unknown[]) {
        // Exclude the tracking table itself to prevent write loop
        if (query.includes('"api_usage"')) return;
        const table = query.match(/(?:from|into|update)\s+"?(\w+)"?/i)?.[1] ?? "unknown";
        const queryType = query.trimStart().split(" ")[0].toLowerCase();
        trackEvent({ kind: "db_query", table, queryType });
      },
    }
  : undefined;

export const db = drizzle(sql, { schema, logger });
```

## Dashboard query examples

These work with Drizzle or raw SQL in Neon:

```sql
-- Total estimated Anthropic spend this month, by model
SELECT model, SUM(cost_usd) as total_cost, COUNT(*) as calls
FROM api_usage
WHERE kind = 'anthropic'
  AND created_at >= date_trunc('month', now())
GROUP BY model
ORDER BY total_cost DESC;

-- Slowest API routes this week
SELECT path, AVG(latency_ms) as avg_ms, COUNT(*) as calls
FROM api_usage
WHERE kind = 'route'
  AND created_at >= now() - interval '7 days'
GROUP BY path
ORDER BY avg_ms DESC
LIMIT 20;

-- External API error rate by service
SELECT service, COUNT(*) FILTER (WHERE error IS NOT NULL) as errors, COUNT(*) as total
FROM api_usage
WHERE kind = 'external'
  AND created_at >= now() - interval '24 hours'
GROUP BY service;

-- Per-user Anthropic spend today (for budget enforcement)
SELECT user_id, SUM(cost_usd) as spend_usd, SUM(input_tokens + output_tokens) as total_tokens
FROM api_usage
WHERE kind = 'anthropic'
  AND created_at >= date_trunc('day', now())
GROUP BY user_id
ORDER BY spend_usd DESC;
```
