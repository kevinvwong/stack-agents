# Module: i18n

next-intl internationalization for Next.js 15 App Router. Used in GTLI projects serving non-native English speakers. Handles locale routing (`/en/`, `/es/`, `/ar/`), translation files, pluralization, and RTL layout switching.

## Why this module

- Language learning platforms serve learners in their native language
- next-intl is the most complete i18n solution for App Router with Server Component support
- Locale routing handles SEO correctly (no duplicate content, proper hreflang)
- RTL support needed for Arabic, Hebrew, Farsi learner populations

## Install

```bash
npm install next-intl
```

## Scaffold

**Directory structure:**
```
messages/
  en.json
  es.json
  ar.json
middleware.ts
i18n/
  routing.ts
  request.ts
app/
  [locale]/
    layout.tsx
    page.tsx
```

**i18n/routing.ts:**
```ts
import { defineRouting } from "next-intl/routing";

export const routing = defineRouting({
  locales: ["en", "es", "ar"],
  defaultLocale: "en",
});
```

**middleware.ts:**
```ts
import createMiddleware from "next-intl/middleware";
import { routing } from "./i18n/routing";

export default createMiddleware(routing);

export const config = {
  matcher: ["/((?!api|_next|_vercel|.*\\..*).*)"],
};
```

**messages/en.json (starter):**
```json
{
  "nav": {
    "home": "Home",
    "lessons": "Lessons",
    "practice": "Practice"
  },
  "lesson": {
    "start": "Start Lesson",
    "continue": "Continue",
    "complete": "Complete"
  }
}
```
